设置与诊断

怎么用

  1. 写稿：在中央稿纸写下或粘贴文本。长文会自动分段。
  2. 选音色：左侧点选一个音色；没有合适的就去「克隆」上传一段自己的声音。上传后会自动把录音里的话识别成文稿，对照录音核对一遍就能保存（识别不可用时手工填写）。
  3. 调风格：情绪、口音、语速按需选择；高级参数里可以固定种子复现结果。
  4. 生成：点「生成语音」或按 Ctrl/⌘ + Enter。进度会显示当前在第几段。
  5. 试听与下载：生成完右侧播放器可直接试听和下载 WAV；历史里可以重播或复现。
  6. 剧本台：按「角色：台词」写对白，## 场次 分组，[情绪] 标注语气。角色卡片定音色、默认情绪、语速与口音；场次可设氛围，对整场生效。保存时会自动把新出现的角色配好音色。
  7. 铺底与出片：先到「素材库」生成噪声底或上传自己的环境声，再到场次卡片里给每一场选环境声 / BGM 与音量。改完会自动重算混音（干声整轨不动）；点「一键出片」一次跑完合成 → 拼接 → 混音 → 打包下载。
  8. 导出：整轨、分行音频、时间轴、剧本、字幕、混音按需勾选；字幕与混音默认不勾，避免导出的包悄悄变大。

已知限制

下面这些不是 bug，是当前模型与部署条件决定的，已尽量在界面上标出来。

  • 同一句里不会多人同时说话：模型一次只念一句。想让两句叠着说，用剧本台每行的「抢话」按钮给它一个提前量（0.3 / 0.6 / 0.9 秒），重叠发生在拼接出的时间轴上。
  • 情绪只按行判断：上一行的语气不会自动带到下一行。需要延续时打开剧本台的「情绪跨行延续」，或在台词里标注 [情绪]；显式标注永远优先。
  • 环境声不是 AI 生成的：只能用你自己上传的素材，或用素材库生成的噪声 / 雨 / 火 / 街道（都是程序合成的，不是采样录音）。没有「描述一句就自动配真实雨声」这回事。
  • 克隆音色不吃情绪指令：克隆模型不接受自然语言指令，克隆角色的情绪与方言标注不会生效（台词旁会标出来）；想让情绪生效，请把该角色换成设计型音色。
  • 同时只跑一个合成任务：8 GB 显存跑不动并行，第二个任务会排队（进度条上显示排第几位，可直接取消）；同一个剧本同一时间只能有一个任务。
  • 大剧本要分批：一次最多 300 行，更多请分剧；每批 100 行，跑完自动续做。
  • 混排音色会更慢：设计型与克隆型音色混用时，合成会按路线分组以减少模型加载，但整剧耗时仍比单一路线长。

数据全部保存在本机 data/ 目录，不会上传到任何外部服务。
